## 📖 应用简介

**事半·SemiDone** 是一款专为 Windows 用户设计的轻量级桌面待办应用。它采用现代化的技术栈，提供流畅的用户体验，帮助你高效管理日常任务。

> 💡 **名字由来**：「事半」取自成语「事半功倍」，寓意用更少的时间完成更多的事情。SemiDone 则是 Semi（一半）+ Done（完成）的组合，呼应中文名的含义。

## ✨ 核心特性

### 🎯 任务管理

- **快速创建**：一键添加待办，支持标题、描述、优先级、截止日期
- **附件上传**：支持任意文件类型，拖拽/粘贴上传，单文件最大 10MB
- **周期循环**：支持按天/周/月重复，完成后自动创建下一个周期任务
- **优先级标记**：高/中/低三级优先级，重要任务一目了然
- **智能筛选**：全部/待办/已完成/逾期/今日，快速定位任务
- **实时搜索**：关键词搜索，瞬间找到目标任务

### 🎨 个性化体验

- **三套主题**：明亮、深色、梦粉，满足不同审美需求
- **透明模式**：深色主题专属，1%-100% 透明度可调
- **励志名言**：待办页日期旁及折叠栏自动轮播
- **液态玻璃 UI**：提供标准、极致两档预设和可拖动预览，导航文字与图标保持清晰
- **全局外观**：支持统一字号与独立界面动效开关
- **用户资料**：自定义头像和用户名，打造专属体验

### 🧘 Zen（禅·极简模式）

- **专注待办**：仅展示未完成任务，半透明面板搭配自定义字号、文字颜色与背景配色
- **独立窗口**：与完整模式分别记忆窗口尺寸，支持小窗口、顶部拖动与置顶
- **简洁操作**：仅勾选框可完成任务，完成后划线飞出，减少误操作
- **随时切换**：在设置中启用 Zen，通过标题栏图标进入；点击返回图标或按 Esc 退出

### 🪟 窗口控制

- **窗口置顶**：原生置顶守护，支持 Win+D 返回桌面后的窗口恢复，托盘唤醒保留置顶状态
- **窗口折叠**：折叠为迷你条或悬浮球，不遮挡工作区域
- **关闭到托盘**：默认仅隐藏窗口，从托盘显示恢复或明确退出，可在设置中关闭
- **悬浮球**：折叠后显示为圆形悬浮球，点击展开
- **开机自启**：可在设置中开启开机自动启动
- **自定义标题栏**：无边框设计，简洁美观
- **拖拽移动**：标题栏可拖拽，随心摆放位置

### 🎉 交互反馈

- **完成动画**：卡片淡化后向右滑出，列表自动补位，不弹出全部完成提示
- **操作提示**：保留操作失败与新版本提醒，减少重复成功提示
- **进度统计**：实时显示任务完成进度，可折叠/展开
- **循环标识**：周期任务卡片显示重复图标
