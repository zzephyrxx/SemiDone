# 搜索栏分离及导航玻璃可见性修复

2026-10-26，分支 `codex/v7.0`。本轮修改未提交推送。

## 重新核对 FlClash 后的定位

上一版只关注 `LiquidGlassStyle.lens` 的透明 tint，遗漏了导航外层底板和实际绘制顺序。FlClash 的 [`navigation_dock.dart` 1345–1510 行](https://github.com/chen08209/FlClash/blob/7fd417fb9a9a277c6a9339a8ac87f907df7c25f7/lib/ui/navigation_dock.dart#L1345-L1510) 明确分别绘制 `_Lens`、`_GlassLens`、菜单项目；`_Lens` 有主题相关底色，`_GlassLens` 的说明也明确菜单内容位于其上。透明 tint 不能直接等同于“整个选中块全透明”。

SemiDone 上一版将整个选中块的底色移除，又把透镜放到菜单文字上方，透镜还覆盖较宽的上下区域：这会同时造成浅色主题选中态不可见和文字被折射的问题。新实现改为底板、透镜、文字的顺序。

## 改动

- 搜索文字从 11px 调为 12px，继续跟随全局字体比例；不改变 34px 控件高度。
- 吸顶行仅负责定位，不绘制背景、阴影或背景滤镜。玻璃材质移到搜索输入框自身，新建按钮继续独立绘制，8px 间隙不再被一块底层材质连接。
- 导航滑块使用两个同步移动的元素：带少量主题色及高光的半透明底板、透明光学层；两个元素均在文字下方。全透明的是光学层，用户看到的整个滑块有底色。
- 网页导航透镜的折射和色散收窄到约 4px 边缘，1.5–4px 平滑衰减。默认基础采样最大偏移约 1.2px，4px 内侧之后折射和通道偏移均为零，避免上下大片映像。普通弹窗仍保留原有倒角曲线。
- 在色散开启时补充约 1px、遮罩裁空中心的冷暖边缘高光，让纯色背景上的轮廓仍可辨认。这是 CSS 材质高光；真实背景通道分离仍由 SVG 位移图实现，二者不是同一机制。不在内容中心绘制彩色填充，不给普通按钮增加黑灰底。
- 深色主题降低大面积白色高光，玻璃填充更通透，同时提高细边缘可见度；导航底板独立使用较低高光，避免沿用浅色的大面积白光。

保留玻璃总开关、色散开关、系统强制颜色回退和独立动效开关。没有移植 Flutter 的截图、弹簧或内容形变运行时，也没有声称与 Android GPU 输出完全一致。
