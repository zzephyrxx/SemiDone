# SemiDone 更新日志

## 2026-07-17｜SemiDone 5.0.0

SemiDone 5.0 在前置架构整理的基础上完成任务统计视图、版本更新检测、待办置顶和透明模式可读性优化。每项功能均按“先写失败测试、实现、独立回归”的顺序完成。

### 1. 日历式任务视图

- 新增“任务视图”入口，支持按周、月查看完成数量。
- 月视图以 6 周日历网格展示每天完成密度，点击日期可进入当日详情。
- 周视图展示本周每日完成分布，月视图展示当月完成密度。
- 新增独立 `completedAt` 完成时间，完成后继续编辑不会篡改完成日期，重新打开任务时会清除完成时间。
- 旧数据没有 `completedAt` 时兼容使用原 `updatedAt`，无需手动迁移。

### 2. GitHub Release 更新检测

- 应用启动后每个会话自动检查一次最新 GitHub Release；只有发现新版本时才提示用户。
- 更新检查已合并到设置页“关于”中的“当前版本”一行：无更新时保持简洁，发现新版本时显示可点击的胶囊提示，点击前往对应 GitHub Release；检查失败时提供紧凑的重试入口。
- 修复 GitHub 匿名 REST API 配额耗尽时出现 `403 rate limit exceeded` 的问题：桌面端改用 Tauri 官方原生 HTTP 跟随本项目 Release 页面重定向，不再依赖匿名 API 配额或用户 Token。
- 兼容 `SemiDone-v5.1.0` 形式的 Release 标签，能够正确提取并比较 `5.1.0`。
- 原生 HTTP 权限仅允许访问 `zzephyrxx/SemiDone` 的 Releases 路径，不开放其他网络地址。
- 更新跳转仅允许打开 `zzephyrxx/SemiDone` 项目的 GitHub Releases 地址。
- 当前版本实现“检测新版本 + 前往 GitHub 下载”，不会静默安装更新。
- Tauri 官方应用内更新安装依赖长期保存的签名私钥、公钥和签名产物；在配置发布签名后可继续升级为应用内下载和安装。

### 3. 待办卡片置顶

- 每张待办卡片新增置顶/取消置顶按钮。
- 已置顶任务在标题旁显示可点击的实心图钉，点击即可取消置顶；图钉跟随浅色、深色和粉色主题主色。
- 移除置顶卡片整圈黄色描边，避免与已完成、逾期和到期状态的卡片样式冲突。
- 置顶后不再常驻显示编辑和删除按钮；这些操作仅在鼠标悬浮或键盘聚焦卡片时显示。
- 置顶任务在所有筛选结果中优先展示，并继续遵循用户选择的日期、优先级或更新时间排序。
- 普通已完成任务在“全部”视图中仍保持在末尾；主动置顶的已完成任务保持置顶。
- `isPinned` 同时支持浏览器 localStorage 和桌面端 JSON 持久化，旧任务默认未置顶。

### 4. 透明模式可读性

- 仅在透明模式激活时提高 `text-muted-foreground` 的亮度。
- 兼容项目中仍在使用的 `text-gray-500/600/700` 灰色工具类。
- 提升输入框和文本域占位符对比度，并增加轻微深色文字阴影，以适应桌面背景变化。
- 普通浅色、深色和粉色主题不受此次覆盖影响。

### 5. 任务视图与操作反馈精简

- 任务视图移除日视图，只保留周视图和月视图。
- 顶部任务视图按钮补充与相邻操作一致的“任务视图”悬浮名称回归检查。
- 修复折叠为条状后励志名言停在第一条的问题，恢复每 5 秒切换并保存当前索引。
- 修复主页面点击取消置顶、编辑等任务卡片操作后列表自动滚回顶部的问题；任务更新和行内编辑会保留当前位置，切换筛选、搜索或排序时仍会回到顶部。
- 删除任务、重置设置、清除数据、迁移数据目录、导出报告、保存番茄钟设置和番茄钟阶段切换不再显示成功弹窗。
- 取消导出时不再显示额外提示。
- 操作失败提示和发现新版本提醒继续保留，避免隐藏需要用户处理的信息。

### 6. 设置页界面优化

- 设置页改为“外观与交互”“数据与记录”“关于”三个紧凑分组，减少每项功能独占大卡片造成的页面长度。
- “外观与交互”使用双列布局，完整保留明亮、深色、梦粉主题、开机自启动、透明模式、透明度和悬浮球模式。
- “数据与记录”将记录导出、数据目录和数据管理合并为三行列表；数据目录直接显示在对应行中，打开、更改和清除入口保持不变。
- 删除独立的“软件更新”卡片，将检测结果放入“当前版本”行；只有发现新版本或检查失败时才出现额外操作。
- 公众号区域默认折叠为单行入口，点击后再显示二维码，进一步缩短初始页面高度。
- 卡片、文字、边框和交互状态继续使用主题变量，兼容明亮、深色和梦粉三套主题。

### 手动验收建议

1. 新建三个任务并分别完成，切换“任务视图”的周/月，核对数量和任务名称。
2. 完成任务后修改标题，再检查完成日期不变；将任务恢复未完成后，确认它从完成视图消失。
3. 打开设置页，确认“当前版本”行自动发现远端 `5.1.0` 并显示胶囊提示；点击后应打开对应 GitHub Release，且不再出现独立的“软件更新”卡片。断网时应出现“重新检查”入口。
4. 置顶不同优先级和完成状态的任务，分别切换浅色、深色和粉色主题：确认标题旁图钉清晰可点，卡片没有黄色描边，未悬浮时编辑和删除按钮保持隐藏；重启后确认置顶状态和排序仍存在。
5. 开启深色主题与透明模式，将透明度调低，在浅色和复杂桌面壁纸上检查灰色说明文字与输入占位符。
6. 分别切换明亮、深色和梦粉主题，检查设置页双列布局、三行数据区和版本胶囊；点击公众号入口，确认二维码可展开并可再次折叠。

## 2026-07-16｜SemiDone 5.0 开发前置整理

本次更新集中处理数据持久化、Tauri 降级策略和大型组件维护性三个问题，为 SemiDone 5.0 的后续功能开发建立更稳定的基础。三个问题均按照“修复一项、验证一项”的顺序完成，并在最后执行了完整回归。

### 1. 集中数据持久化

- 新增统一的使用数据持久化服务，将使用记录、周/月统计、每日开始时间和番茄钟状态统一管理。
- 桌面端使用 `usage.json` 作为使用数据的唯一持久化文件，由 Rust 存储层负责读取、保存和清除。
- 浏览器开发环境继续支持 localStorage，但统一保存为一份带 `schemaVersion` 的使用数据文档。
- 增加旧版 localStorage 数据迁移：只有新存储写入成功后，才会清除旧键，避免迁移过程中丢失数据。
- 设置状态不再同时由 Zustand persist 和后端保存，后端存储成为设置数据的唯一来源。
- 使用统计页面改为直接读取统一的 usage store，不再自行读取零散 localStorage 键。
- 删除未被项目使用、且会形成重复持久化路径的 `userStore`、`UserProfile` 和 `useTheme`。

### 2. 修复 Tauri 降级造成的数据分叉

- 重构前端 Tauri API 边界，明确区分浏览器环境和桌面环境。
- 只有应用确实运行在浏览器中时，任务、设置、使用数据和导入导出接口才会使用 localStorage 适配器。
- 桌面端 Tauri 命令执行失败时，不再静默降级到 localStorage，而是返回带命令名称的明确错误。
- 附件、自动启动和数据目录等桌面专用能力在浏览器中统一返回“Tauri不可用”，不会产生伪成功状态。
- 统一附件打开、数据目录迁移等调用入口，减少组件直接依赖底层 Tauri 命令。
- 修正数据导入命令参数命名：前端使用 `jsonData`，Rust 使用 `json_data`，符合 Tauri 2.0 的驼峰/蛇形转换规则。

### 3. 拆分大型组件

#### 重复规则编辑器

- 新增公共 `RecurrenceEditor` 组件。
- `QuickAddTask` 和 `TaskDetail` 复用同一套按日、按周、按月重复规则编辑逻辑。
- 重复规则文本格式化迁移到独立工具模块。
- `QuickAddTask.tsx` 从约 681 行减少到 510 行。

#### 任务附件区域

- 新增 `TaskAttachmentsSection` 组件。
- 独立负责附件编辑、预览、系统打开、打开所在目录和浏览器 Base64 打开逻辑。
- `TaskDetail.tsx` 从约 962 行减少到 632 行。

#### 设置页面

- 设置页面拆分为以下组件：
  - `AppearanceSettingsSection`
  - `DataSettingsSection`
  - `AboutSettingsSection`
  - `DataDirectoryDialog`
- `Other.tsx` 从约 734 行减少到 230 行。
- 清除数据、打开数据目录和迁移数据目录统一通过 API 层调用。
- 开启/关闭悬浮球、开机自启和窗口置顶时不再显示成功弹窗；操作失败时仍会显示错误提示。
- 设置页已移除“打赏开发者”区域及微信、支付宝打赏二维码。

### 兼容性说明

- 旧版使用统计和番茄钟数据会在首次读取时自动迁移，无需用户手动处理。
- 桌面端数据仍保存在当前配置的数据目录中，数据目录迁移能力保持不变。
- 更改数据目录时，`tasks.json`、`settings.json` 和 `usage.json` 会一起迁移，使用统计不会遗留在旧目录中。
- 浏览器开发模式仍可独立运行，但其 localStorage 数据不会与桌面端数据互相覆盖。
- 本次整理未变更现有的 SemiDone 4.0.17 版本号和启动更新提示内容。
