# 液态玻璃范围收缩与搜索图标修复

2026-10-26，`codex/v7.0`。本轮按用户最新要求，替代此前将玻璃广泛应用到页面内容的方案。改动保留本地，未提交推送。

## 原因与处理

此前通用样式通过 `.card`、`.task-card`、搜索输入框等选择器自动添加背景模糊、折射与色散，同时叠加阴影。搜索图标与输入框重叠时存在被背景采样的路径，普通内容区也因多层材质和阴影而发灰。

- 玻璃改为显式启用，仅保留悬浮导航及其选中透镜、关键弹窗、设置实时预览。`Surface` 默认普通面板不再开启滤镜或生成 SVG 滤镜定义，也不注册玻璃尺寸观察器。
- 搜索区恢复普通表面：输入框层级为 0，搜索图标为 1，清除按钮为 2；图标不接收指针事件，明确禁用自身滤镜。输入框使用块布局，避免行内基线留白影响垂直定位。
- 移除普通任务卡、统计卡、设置卡和标题栏的玻璃处理；同时覆盖梦粉及透明模式的旧模糊规则，避免主题切换后重新生效。开启玻璃不再修改这些普通内容的背景。
- 清除本轮玻璃层上的外阴影与内阴影，包括导航、透镜和弹窗；保留细边界及必要的输入焦点提示。弹窗打开时原有背景遮罩继续用于区分前后层次。
- 设置说明同步调整为“仅用于悬浮导航、关键弹窗与实时预览”。导航拖动、边缘色散、任务退场及其他已实现动效保持原逻辑。

## 验证

- 全套 215 项，211 通过。仍有 4 项既有打赏功能测试失败：打赏二维码开关、参考动画序列、五个独立拖动样本、打赏弹窗拖动边界。未删除、跳过或改写这些失败来掩盖问题。报告：`docs/ui-glass-scope-test-results.json`。
- 最后一处搜索布局调整后，实际待办搜索流程与材质回归共 18 项全部通过。覆盖玻璃开关反复切换、搜索及清除功能、图标前景层级、普通面板无滤镜，以及明亮／梦粉／深色配合透明模式的普通内容背景稳定性。
- TypeScript、改动文件 ESLint、Vite 生产构建通过；既有 Browserslist、混合导入和包体积提示仍在。
- 截图工具报 `window capture timed out`。以上包含真实样式表的 DOM 回归，不等同于 Windows WebView2 的实际像素或玻璃观感验收。
