# 完成任务时的提示与横向滚动条修复

2026-10-27，`codex/v7.0`，修改保留本地。

首页移除“所有待办已完成”的浮动提示、对应样式、状态订阅及自动关闭计时器。原有统计、完成记录和页面空状态继续显示。

底部浅灰条来自任务退场的横向溢出：卡片向右平移超过可视宽度，任务列表允许溢出；首页只设置纵向自动滚动时，横向也会成为可滚动轴。现在只在退场行裁切溢出，避免动画扩展祖先的滚动宽度，同时明确首页横向隐藏、纵向自动滚动。淡化、右滑、列表补位、普通行与编辑行保持原逻辑。

首页真实工作流、滚动位置、虚拟列表及任务退场共 22 项检查通过；补充验证了最终任务完成不再出现提示、退场行裁切且仍播放动画、普通行不被裁切，以及首页只允许纵向滚动。TypeScript、修改文件 ESLint 和生产构建通过。开发服务器返回的首页模块已不含提示节点。

这些是代码、样式及 DOM 回归结果；未取得真实浏览器动画帧截图。刷新 [v7 预览](http://127.0.0.1:5177/v7-preview.html) 可检查完成任务时的窗口底部。
