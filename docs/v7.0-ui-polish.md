# V7 界面与窗口交互补充交付

日期：2026-10-29。分支：`codex/v7.0`。版本保持 `7.0.0`，承接 `43cabfb8` 之后的开发改动；只推送开发分支，不合并 master，不发布安装包或 Release。

## 本次整理的行为

- 待办、日历、统计和设置统一导航间距，移除重复的返回入口；新建、详情与卡片编辑布局收紧，长网址换行，任务描述正常展示。
- “全部”包含所有任务，未完成在前、已完成在后；组内保留置顶与当前排序。完成状态图标使用相同尺寸。
- 日期时间使用应用内控件，避开置顶窗口与原生弹出层的冲突；卡片编辑和新建入口共用独立日期弹窗，尺寸为最初版本的约 90%。重复设置贴近按钮定位，空间不足时翻转，内容增长或窗口调整后重算位置。
- 补齐截止日期显式清除的浏览器与 Rust 持久化逻辑；新建描述框支持拖动调整高度。
- 统计页设置弹窗、设置页 Zen 配置区和 Zen 窗口配置面板跟随全局液态玻璃开关及标准／极致预设，关闭后恢复纯色。普通任务区域保持原有透明度设置，控件不逐个添加玻璃。
- Zen 配置使用紧凑三列滚轮，带滚动阻尼；预览复用任务行字号与布局。字体预览缩小，“重置”图标按钮移至百分比左侧。
- 提示延迟改为 1 秒；顶部导航不加悬浮提示。移除玻璃实时预览区，调整标题栏 Logo、条状高度与圆角。
- 禁用展开、条状、悬浮球内容区的右键菜单，并拦截 Windows 标题栏菜单；悬浮球改用左键原生拖动，等待实际拖动结束后计算屏幕边缘吸附，不更换现有置顶策略。
- 子弹窗只响应最上层 Esc／Tab，关闭后恢复焦点；背景交互锁在嵌套卸载时正确释放。保留公告在 Zen 窗口中的隐藏规则及紧凑模式的弹窗限制。
- 保留当前工作区的关闭弹窗与数据目录说明文案调整。
