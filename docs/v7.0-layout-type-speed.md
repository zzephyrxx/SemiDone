# 导航文字色散、四页排版与动效提速

2026-10-26，`codex/v7.0`。本轮修改保留在本地，未提交推送。

## 导航文字色散

设置页实时预览在玻璃小窗下绘制文字与背景图形，再通过 `liquidGlassBackdrop` 和 `LiquidGlassFilters` 采样这些内容。导航使用同一组滤镜，但上一版将菜单文字放在光学层上方，因此滤镜采样不到菜单文字。

本轮改为：中性玻璃底板 z=0、菜单文字 z=1、透明光学层 z=2。底板仍在文字下方，避免遮盖正文；透明光学层可以在拖动经过文字时对其做边缘通道分离。继续保留约 8px 色散渐隐、约 4px 以内的浅折射，中心为原采样，不恢复整块上下映像或固定彩色描边。

强制颜色及不支持 backdrop-filter 时，光学层回到文字下方，避免实色回退挡住文字。

## 标题、边距和字号

- 统计页移除“我的使用时长”“追踪您的使用习惯，提升效率管理”。
- 设置页移除页首“设置”及其引导短句，功能分组标题继续用于识别内容。
- 四页统一使用与待办页相同的顶部内容偏移和内边距：默认导航预留 68px、内容上内边距 8px；低窗口上内边距 6px；宽屏侧栏布局顶部预留 0、内容上内边距 16px。窄/宽布局的横向边距也由同一组变量维护。
- 用户澄清“字体设置为一”指字号一致。本轮没有改字号滑块步长或重置已保存值，而是让四页共用正文 13px、分区标题 14px、说明 11px 的层级；搜索及编辑描述保留 12px 的紧凑角色。以上均乘以全局字体比例。任务标题与编辑输入使用相同字号，统计数字与计时器继续承担数值强调。

这些是共享布局规则和样式计算结果，不等同于已经取得四页的实际像素截图。

## 动效速度

一般界面过渡按速度 1.5 倍处理，即原时长约 2/3；任务完成按速度 2 倍处理。保存操作仍等待真实写入完成，不缩短持久化过程。

| 动效 | 原时长 | 新时长 |
| --- | --- | --- |
| 反馈/开关 | 120ms | 80ms |
| 展开收起 | 200ms | 133ms |
| 导航吸附、列表补位 | 240ms | 160ms |
| 弹窗进入/退出 | 180/150ms | 120/100ms |
| 页面淡入 | 180ms | 120ms |
| 展开模式完成退场 | 420ms | 210ms |
| Zen 保存提示最小周期 | 325ms | 163ms |
| Zen 完成退场 | 750ms | 375ms |

展开模式仍由 animationend 正常移除，250ms 兜底；Zen 计时与 CSS 同时减半，避免只改视觉时长而仍留下原来的等待。相关通用 hover/按压、玻璃材质和滑块反馈也作相应提速。动效开关继续独立控制，遵循本轮前用户明确指定的应用开关优先关系。
