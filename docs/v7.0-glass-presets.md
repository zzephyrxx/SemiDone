# 导航清晰度与两档玻璃预设

2026-10-27，`codex/v7.0`。用户已确认只保留“标准”“极致”两档。本轮修改留在本地，未提交推送。

## 行为

导航选中项模糊来自玻璃透镜位于文字和图标之上。现在底板、透镜都位于导航前景下方；导航链接、文字和图标明确不应用滤镜，点击、拖动选页和按压反馈保持原逻辑。设置中的两档预设直接展示，删除手动滑块、独立色散开关和配置展开入口；保留玻璃总开关与可拖动的实时预览。

| 参数 | 标准 | 极致 |
| --- | --- | --- |
| 模糊程度 | 9 档 | 4 档 |
| 扭曲强度 | 0% | 0% |
| 边缘过渡 | 10% | 50% |
| 中心放大 | 0% | 7% |
| 色散 | 关 | 开 |

旧自定义配置在浏览器读取和应用设置加载时迁移到标准，保留启用／关闭状态。选定预设后，由统一配方生成参数，旧字段不会覆盖配方；关掉再打开玻璃会保留已选预设。应用设置保存失败时恢复之前的选择。

色散与扭曲解耦，所以极致模式在扭曲为零时仍有独立、渐隐的边缘通道分离；不会作用于导航前景文字。标准模式只有背景模糊，不再为它生成无用折射贴图。原生设置模型新增预设标识以保留重启后的选择；既有光学字段继续兼容。
