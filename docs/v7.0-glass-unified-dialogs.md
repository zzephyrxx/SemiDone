# 玻璃比例统一、采样精度与弹窗行为

> 后续已改为两档预设，并将导航玻璃移到文字下方，见 [导航清晰度与预设](v7.0-glass-presets.md)。此文件保留上一轮实现记录。

2026-10-26，`codex/v7.0`。本轮修改保留本地，未提交推送。此说明替代上一轮按参考像素强度和窄导航特殊减弱的方案。

## 玻璃配置与采样

- 导航底板、选中透镜、关闭／公告及其他已有玻璃弹窗共用 `Surface`、`LiquidGlassFilters` 和参数归一化逻辑；设置实时预览使用同一滤镜。普通页面卡片和按钮不因此新增玻璃。
- 关闭、公告、删除、清空缓存及导出弹窗不再只引用固定 320×240 滤镜。打开时立即测量完整边框盒，之后随实际尺寸更新；不使用排除内边距的内容盒，也不把小控件尺寸按 8px 取整。
- 扭曲强度按短边半径的百分比计算，过渡宽度按中心到边缘的比例计算。不同大小使用相同归一化分布；圆角仍按各自真实形状适配。模糊也按尺寸调整，取消滑块强制零模糊的独立分支。
- 色散遮罩从二值开关改为连续灰度渐隐，颜色偏移沿边缘法线变化，中心保持无色散。没有新加彩色边框或人为的硬分界线。
- 位移原语使用 CSS 像素坐标，取消将宽高比压入 8 位贴图通道的做法，避免宽而矮的导航仅剩少量横向位移档位。小控件按 1 CSS 像素采样，贴图上限 1024×512；位移图缓存最多 8 项、编码数据总量最多 16 MiB。编码按小块进行，拖动位置不进入贴图缓存键。
- 设置名称改为“扭曲强度”“边缘过渡”“中心放大”，均使用百分比显示；内部字段继续读取已有配置，预览／松手保存的边界不变。

以上修正针对用户截图中导航大面积失真、边缘分界及拖动时块状失真的实现路径。真实 GPU 输出仍需要目视验收，样式与数值测试不能证明最终画面质量。

## 弹窗

- 关闭和公告弹窗支持拖动标题区域，取消／关闭等按钮不会触发拖动；支持标题区域方向键移动、Shift 加大步长。
- 拖动过程中合并绘制更新，不逐次重绘 React、不重新生成光学贴图，也不逐次读取布局。指针取消、丢失捕获和窗口失焦会结束拖动；窗口缩小时会重新约束位置。
- 共用弹窗生命周期禁止条状、悬浮球模式展示弹窗，并立即移除已打开或正在退场的弹窗。尚未展示的公告保留到展开后显示，不会自动写入“不再显示”。完全展开和 Zen 模式允许展示。
- 关闭到托盘仍走原来的原生关闭策略。禁用关闭到托盘时，从条状／悬浮球请求退出会先展开，确认框仅在展开后显示；取消此前依靠 300ms 延迟显示的分支。紧凑模式也不挂载全局通知层。
