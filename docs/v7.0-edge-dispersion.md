## 本轮改动

1. 将普通折射和边缘通道偏移拆成独立场；增加仅覆盖边缘的遮罩，中心直接保留基础折射采样。导航使用凸起透镜曲线，普通面板使用内收倒角。
2. 色散开关只切换光学滤镜，不再切换整块表面的 saturation、contrast、brightness。模糊先执行，再计算边缘折射与通道采样。
3. 导航透镜取消整块填充、黑色外阴影，只保留细白色轮廓；置于导航文字上方且不接收鼠标事件，让移动边缘能采样经过的文字。实色及强制颜色模式将选中底板放回文字下方，避免遮住文字。
4. 以直通 RGB 重组颜色，再恢复基础采样 alpha；边缘混合不扩大透明覆盖范围。相比上游取三个采样 alpha 最大值，这里采用更保守的基础 alpha，避免网页透明背景上产生整块覆盖。
5. 显式使用 sRGB，解码时令字节 128 严格对应位移中点 .5；位移图使用 objectBoundingBox 单位，并补偿纵横比，让位移图不随滤镜外围留白被拉伸。依据：[MDN 颜色空间](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/color-interpolation-filters)、[W3C 滤镜单位、透明度和位移定义](https://www.w3.org/TR/filter-effects-1/)。
6. 缓存最多 8 组几何/强度组合，图像分辨率有上限。导航仅发生位置变化时复用位移图；几何或折射强度改变时才生成新图。未加入全页逐帧截图或 JavaScript 动画循环；这不等同于已经测得 GPU 帧率提升。

`Surface` 导航与选中透镜使用 ResizeObserver 测量的尺寸，边缘范围约为 10 CSS px（受 8px 尺寸量化和位移图插值影响）。普通卡片和旧弹窗继续使用共享默认形状，边缘宽度随实际表面尺寸缩放；并非所有元素都已实现固定 10px 的逐元素几何。没有新增产品模式或改动用户已保存的模糊、折射、色散参数。
