# V7 第二轮：共享交互与玻璃材质

> 本文保留上一轮的交付记录。用户反馈后的全局玻璃恢复、删除重复模式、悬浮导航、字体与编辑布局修复，以 [第三轮修订说明](v7.0-ui-round3.md) 为准。

日期：2026-10-26。分支：`codex/v7.0`。本轮交付为可运行代码和回归证据，尚未发布安装包，也尚未提交或推送本轮修改。

## 本轮范围

上一轮完成首页、设置页的布局与视觉原型。本轮把「任务完成与补位」「设置展开、玻璃预览与提交」两条流程接到可复用组件，并处理重复操作和更新范围。保持 React / Tauri / Zustand，无新增依赖；托盘生命周期与现有未提交的自启动、Zen、发布信息等修改均保留。

借鉴对象及固定版本见 [源码审计](v7.0-ui-deep-audit.md)。借鉴的是按 ID 管理列表过渡、可中断展开、表面层级、边缘法线和局部更新的思路；本项目独立实现，没有引入 Dart 源码、Flutter shader 或上游品牌资源。

## 已实现

| 部分 | 实际行为 | 主要文件 |
| --- | --- | --- |
| 动效策略 | 按压 120ms、展开 200ms、列表 240ms、浮层进入 180ms；遵循系统减少动效 | `src/ui/motion.ts`、`src/styles/ui.css` |
| 任务完成 | 保存期间禁止同一任务重复提交；仅保存成功后反馈完成；保存失败不生成循环子任务、不庆祝 | `TaskItem.tsx`、`taskStore.ts` |
| 列表过渡 | 稳定任务 ID；删除/完成筛出时短暂保留退出行，禁止其接收交互，再让邻行补位；快速恢复取消退出；超过 24 项增删直接更新；筛选/搜索/排序切换直接重置 | `AnimatedTaskList.tsx` |
| 长列表 | 保留虚拟化与编辑行高度；仅跨虚拟范围时因滚动重绘；任务更新和编辑保持滚动，筛选变化重置 | `AnimatedTaskList.tsx`、`src/ui/taskWindow.ts` |
| 导航 | 一个共享选中指示块随路由移动，窄窗横向、宽窗纵向复用；窗口模式切回展开时重新测量 | `Layout.tsx`、`src/ui/SelectionIndicator.tsx` |
| 展开 | 统计区、玻璃配置共用可中断展开；关闭时内容立即 inert，过渡后卸载；减少动效时立即切换 | `src/ui/Disclosure.tsx`、`TaskStats.tsx` |
| 浮层 | 新建待办使用 portal、焦点循环、Esc、关闭后返回原按钮；背景 inert 状态在关闭后恢复 | `src/ui/Overlay.tsx`、`QuickAddTask.tsx` |
| 完成反馈 | 全部完成时显示可关闭、2.4 秒自动消失的轻量提示；不再随机播放粒子庆祝 | `Home.tsx`、`taskStore.ts` |
| 玻璃材质 | 实色 / 常规 / 增强；开关关闭为实色，常规与增强沿用现有色散字段，兼容旧设置；导航、新建弹窗共用 Surface | `src/ui/Surface.tsx`、`GlassControls.tsx` |
| 边缘折射 | 将随机噪声场替换为圆角矩形的边缘法线场，中心近似中性；尺寸按 8px 归并，最多缓存 24 张小位图，避免逐帧生成 | `src/ui/glassGeometry.ts`、`LiquidGlassRuntime.tsx` |
| 参数提交 | 滑块在本地预览；松开、取消指针、键盘调节结束、失焦、卸载时提交变化；相同值不重复保存；外部回滚可恢复预览 | `src/ui/useCommittedDraft.ts`、`ParameterSlider.tsx` |
| 拖动预览 | 指针移动按帧合并，只更新预览 transform；结束时同步 React 状态；保留边界约束和方向键移动 | `LiquidGlassPreview.tsx` |
| 订阅 | App、Layout、UsageButton、TaskFilter 等按实际字段订阅；设置页只订阅所需任务 action | 对应组件与 `Other.tsx` |

玻璃用于导航、浮层等有限表面，普通任务与设置卡片保持实色和中性背景。Surface 在不支持 backdrop-filter、高对比度、支持的系统减少透明度条件下退为实色；旧弹窗继续使用兼容样式，尚未全部迁移到 Surface。

边缘法线与 SVG 位图方案不等同于 FlClash 的共享背景采样与物理 shader。当前共用表面按实际尺寸生成位图；未迁移的旧弹窗仍共用默认尺寸比例，后续应逐个接入实测尺寸。Windows WebView2 对 SVG backdrop-filter、色散、圆角和多 DPI 的显示仍需实际验收。

## 审阅方式

打开 `http://127.0.0.1:5177/v7-preview.html`，刷新后查看「第二轮」。浏览器数据与桌面数据分开。

1. 窄窗中新建几条待办，选择「待完成」，完成一条并观察退出、邻行补位；切换筛选检查滚动重置。
2. 连续切换导航与展开统计，检查快速反向操作；新建时用 Tab / Shift+Tab / Esc 检查焦点。
3. 设置中展开玻璃配置，比较常规/增强，拖动参数与预览小窗；关闭开关检查实色状态。
4. 对比 400 / 550 / 1040 宽度、明亮 / 深色 / 梦粉，以及系统减少动效；桌面模式另外检查 100% / 150% DPI 和原生窗口行为。
