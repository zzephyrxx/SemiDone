# SemiDone v7.0 第一版 UI 原型

交付日期：2026-10-25。开发分支：`codex/v7.0`。

## 审阅入口

开发服务运行时打开 <http://127.0.0.1:5177/v7-preview.html>。

审阅页可切换 400 × 700、550 × 900、1040 × 800 三种视口，页面内是实际 React 应用，可创建待办、搜索、完成、编辑及切换设置。浏览器演示使用独立于桌面 JSON 文件的 localStorage；不预先注入示例任务。

若服务已停止，在仓库目录运行：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5177 --strictPort
```

审阅页仅作为开发入口；生产构建仍使用原有 `index.html`。

## 本版设计

- 窄窗横向导航，840 CSS 像素起切换为侧栏。同一组导航入口与当前页高亮，不创建两套导航状态。
- 标题栏保留资料、折叠、置顶、Zen 与关闭操作；条状、悬浮球及 Zen 继续使用各自的布局。
- 首页包含日期、任务概览、精简使用时长、搜索、新建、筛选和任务列表。统计口径沿用现有 Store；完成比例表示全部任务，不声称是今日完成率。
- 三套主题统一为 HSL 语义颜色，默认中性背景、蓝紫强调色；梦粉采用低饱和玫瑰色。普通卡片使用实色；液态玻璃继续由现有弹窗开关控制。
- 设置页增加分组定位与三个可点击主题预览，保留原有透明度、玻璃参数、Zen、自启、悬浮球和数据操作。
- 列表统一使用普通行 104、编辑行 300 CSS 像素计算与渲染，按实际展开高度计算可见区。保留筛选变化重置滚动、更新任务及开始编辑时保留滚动位置的行为。
- 新建对话框补充键盘焦点循环、Esc 关闭与焦点返回。
- 不增加依赖。保留已有未提交的业务和 Rust 修改。

## 验证与边界

改动前：TypeScript 检查通过；全套测试 131 项，其中 127 项通过、4 项失败。

4 项既有失败均位于 `SettingsSections.test.tsx` 的打赏功能用例：当前 `AboutSettingsSection` 没有对应入口。本版不改动该组件、不删除或跳过这些用例。

改动后：TypeScript 检查、Vite 生产构建和本次涉及文件的 ESLint 检查通过。全套测试 137 项，133 项通过、上述同样 4 项失败。新增 6 项覆盖导航、创建持久化、完成与概览更新、搜索清除、统计折叠及取消后焦点恢复。测试完整摘要位于 `v7-test-results.json`（工具生成，可能被仓库忽略规则排除）。

原型已在应用内浏览器加载，可访问性树可读取首页和导航；截图获取超时、点击工具缺少坐标，因此尚未完成目视检查。400/550/1040 布局是已实现且可审阅的目标尺寸，不代表已完成截图验收。尚需实际检查：中文长标题与高 DPI、Windows WebView2 玻璃效果、原生拖动/置顶、Zen 与折叠往返、长列表滚动及编辑的实际布局。

当前交付是首页与设置页原型。日历、统计、详情页沿用现有内容；应用包版本及发布流程保持原状。未打包安装程序、未提交或推送。
