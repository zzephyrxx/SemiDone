## 当前确认的问题

- `useSelectionIndicator` 只按当前路由测量选中项，更新 CSS 位移变量。没有 pointerdown/move/up、指针捕获或拖动选中逻辑，所以拖动导航确实尚未实现。
- `AnimatedTaskList` 会保留退场项 240ms，CSS 同时淡出并向右移动 36px，之后更新列表。不是“先淡化，再向右滑出”的分段效果，也不是完整滑出窗口；全列表中已完成项可能再次出现。
- 应用关闭动效或系统请求减少动效时，`useReducedMotion` 会停止上述效果。目前只确认这一源码分支存在，尚未读到用户当前浏览器的真实媒体查询结果，不能断言它就是用户实测无动画的原因。
- 旧测试确认了状态与定时器变化，没有确认实际帧序列和拖动效果。后续应验证真实操作过程，不能再把存在 CSS 规则当成已完成的体验。

## 已实施的独立外观修正

- 导航滑块底板改用中性玻璃颜色，移除背景和阴影中使用的主题主色，不再产生浅蓝底。光学层仍与可见底板分离。
- 删除固定的彩色 conic-gradient 描边，仅保留真实背景通道分离和中性边缘高光。
- 导航色散范围从约 4px 扩为约 8px，并从边缘持续平滑渐隐；基础折射仍只发生在约 4px 内。位移图本身已渐隐，合成遮罩不再重复衰减一次，避免颜色过早消失。
- 原有搜索框独立背景、12px 搜索字体和透明间隙继续保留。
- 相关 14 项几何/材质检查通过，TypeScript、定向 ESLint、生产构建通过。本轮没有重跑全套测试，也没有新的视觉确认。
