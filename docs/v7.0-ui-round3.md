# V7 视觉与交互修订

日期：2026-10-26，分支 `codex/v7.0`。本轮修改在本地工作区，尚未提交推送或发布安装包。保留已有自启动、Zen、发布信息等未提交修改。

## 用户确认

- 窄窗顶部悬浮导航，宽屏左侧悬浮导航。
- 动效独立开关、默认开启；遵循系统减少动效。
- 删除仅以色散开关区分的重复“增强模式”。

## 修复与实现

| 项目 | 改动 |
| --- | --- |
| 全局玻璃丢失 | 移除工作区中强制实色与禁用 backdrop-filter 的覆盖，统一恢复概览、待办、设置卡片与设置条目的半透明表面、模糊、边缘高光。导航与浮层继续使用独立折射表面。全局玻璃关闭时退为实色；窗口透明模式另按透明度合成，不降低文字透明度。 |
| 重复模式 | 删除“常规/增强”选择，仅保留液态玻璃总开关、模糊、折射、色散。色散是独立参数，不再包装为额外模式。 |
| 悬浮导航 | 主导航脱离内容滚动区，窄窗距顶部悬浮；840px 及以上宽度在左侧悬浮。内容区预留位置，滚动内容可以经过顶部导航下方；宽屏不再绘制一整条分割侧栏。 |
| 导航滑动 | 选中指示块承载玻璃表面，使用自身尺寸的折射场；按路由移动，带轻微缓动回弹。关闭玻璃保留普通选中指示；关闭动效或系统减少动效则立即切换。不是 Flutter 原版 shader、完整弹簧系统或拖拽导航的移植。 |
| 完成动画 | 保存成功后淡出并向右移动 36px，约 240ms。待完成筛选中退出后补位；全部筛选中同样先退出，然后在完成项的新位置显示。快速恢复取消待执行退出；大批完成直接更新，避免排队大量动画。 |
| 全局字号 | 90%–130%，5% 步进，文字样例、当前值与恢复默认按钮。拖动时本地预览，释放/键盘结束/失焦等边界保存。CSS 字号按比例缩放，不使用窗口 zoom；字号增大时列表行相应增高。Zen 的独立字号继续作为基础字号再乘全局比例。 |
| 滑块 | 标签与数值分离到上方；16px 的有进度轨道、细长手柄及轨道间隙、32px 的输入区域、可见焦点。玻璃、透明度、字体及原有复用 ParameterSlider 的设置使用同一控件。 |
| 编辑字号跳变 | 显示标题与标题输入框共用字号规则；描述输入字号统一。移除编辑表单的撑高布局。 |
| 编辑底部留白 | 删除固定 300px 编辑行的实际使用，通过 ResizeObserver 测量真实编辑高度；首帧估算仅在测量前使用，不固定撑大卡片。虚拟化、筛选重置与更新保留滚动继续工作。 |
| 透明度位置 | 放入透明模式本组，在开关下方展开；关闭后折叠并禁止内部交互。拖动预览后提交；折叠或切换透明模式时避免卸载提交意外重新打开透明模式。 |
| 水滴图标 | 液态玻璃使用 lucide Droplet。 |
| 外窗四角 | 主窗口统一使用 `--window-radius: 20px`，根文档透明并裁切四角；Zen 外圆角共用该值。悬浮球维持其圆形窗口形态。原生配置本身已为透明、无装饰窗口，本轮没有更改托盘生命周期。 |

新增的 `fontScale`、`animationsEnabled` 同时接入浏览器存储与 Rust Settings 序列化，旧设置缺字段时分别默认 100%、开启。字体比例在前端加载/保存时做范围归一化。

## 验证与边界

- 修改前：169 项前端测试，165 通过，4 项既有打赏相关失败。
- 修改后：177 项，173 通过，原有 4 项仍失败。新增 8 项全部通过：全部筛选的完成动画、禁用动效、实际编辑高度、透明度位置与提交、移除重复模式、全局字号持久化/恢复、运行时开关、编辑前后标题字号的样式级回归。
- 字号样式级用例使用实际样式表与 jsdom 的选择器级联。因 jsdom 不计算字号中的 CSS 变量乘法，该用例将比例解析为 100% 后验证显示/编辑一致，不代表已完成真实浏览器布局验收。
- 原生 `cargo test --lib`：15 项全部通过，其中新增 2 项检查旧设置缺字段默认值，以及字体/动效字段经过原生序列化后保留。
- TypeScript 检查、改动 TypeScript 文件的定向 ESLint、生产构建通过；`git diff --check` 无空白错误。
- 构建仍有既有的混合静态/动态导入、主包超过 500kB、Browserslist 数据陈旧警告，没有修改警告阈值。
- 预览可访问性树已读到独立动效、全局字号、水滴所属的液态玻璃配置等新结构，页面未白屏。截图工具仍返回 `window capture timed out`，没有进行真实截图比对、帧率/GPU 测量、高 DPI 或原生窗口圆角验收。代码实现与单元测试不等同于这些视觉验证。
